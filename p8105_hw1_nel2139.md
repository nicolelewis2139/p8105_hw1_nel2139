## Description of the dataset

The `penguins` dataset contains size measurements for adult foraging
penguins observed near Palmer Station, Antarctica, including each
penguin’s species, island in the Palmer Archipelago, size (flipper
length, body mass, and bill dimensions), and sex. The dataset has 344
rows and 8 columns and includes the following variables: `species`,
`island`, `bill_length_mm`, `bill_depth_mm`, `flipper_length_mm`,
`body_mass_g`, `sex`, and `year`.

The dataset covers three species (Adelie, Chinstrap, Gentoo) living on
three islands (Biscoe, Dream, Torgersen), observed from 2007 to 2009.
Bill length ranges from 32.1 to 59.6 mm and bill depth ranges from 13.1
to 21.5 mm. Flipper length ranges from 172 to 231 mm, with a mean value
of 200.9 mm. Body mass ranges from 2700 to 6300 g. Sex is recorded as
female or male, and is missing for 11 penguins.

Taking the mean works for the numeric and logical variables but does not
work for the character and factor variables, as the mean function only
accepts numbers, or values it can easily treat as numbers.

The mean of the numeric variable `stnorm_samp` is 0.13, which is the
average of the 10 sampled values. This value is close to 0, as expected
for a standard normal distribution. The mean of the logical variable
`stnorm_samp_pos` is 0.6, which is the proportion of sampled values
greater than 0. This works because TRUE is treated as 1 and FALSE is
treated as 0. The mean of the character variable `vec_char` cannot be
calculated as the variable contains text, which has no numerical value.
The mean of the factor variable `vec_factor` also cannot be calculated
as the variable contains categories with no numeric meaning.

The next chunk of code applies the `as.numeric` function to the logical,
character, and factor variables to attempt to convert them to numeric.
The code is shown but not evaluated.

``` r
as.numeric(pull(prob2_df, stnorm_samp_pos))
as.numeric(pull(prob2_df, vec_char))
as.numeric(pull(prob2_df, vec_factor))
```

Converting the logical variable `stnorm_samp_pos` to numeric turns TRUE
into 1 and FALSE into 0. Converting the character variable `vec_char`
returns NA for every value as the variable contains text with no
numerical value. Converting the factor variable `vec_factor` returns the
numbers 1, 2, and 3, as R stores each factor level as a number, assigned
in alphabetical order.

This helps explain what happens when taking the mean. The logical
variable has a natural numeric meaning, so taking the mean treats TRUE
as 1 and FALSE as 0 and returns the proportion of TRUE values. The
character variable cannot be converted to numbers at all, so its mean is
NA. The factor variable can be converted to numbers, but these numbers
are just labels for the categories with no numeric meaning, so taking
the mean returns NA.
